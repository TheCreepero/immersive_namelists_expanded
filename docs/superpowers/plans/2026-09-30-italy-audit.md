## Rationale
- Linked groups (INF_01, MOT_01, MEC_01/02, ARM_01, PAR_01) are keyed by real division number and written with `%d`, so a number is reserved once across the family (9 'Pasubio' is infantry or autotrasportabile, never both). 136 is shared by INF_01 'Giovani Fascisti' and ARM_01 'Centauro II', as it was historically.
- Unnumbered historical formations (Spanish CTV divisions, Gruppi di Combattimento, partisan formations) stay static names.
- Gating: INF_02 `fascism`; COM_01 simplified to `has_government = communism`; partisans per party (see User decisions); ROM_01 `fascism` and `is_ai = no`. Vanilla's Redshirts template references ITA_INF_02; under the new gate it falls back to generic names, which fits Redshirts better than Blackshirt names.
- R10: MEC_01 became the plain fallback-only group; postwar names moved to new ITA_MEC_02 "Mechanized Divisions (Named)" (links ITA_MEC_01), rewritten as `%da Divisione Meccanizzata '<X>'`.
- COL_03, CAV_04 and CAV_05 became fallback-only: only numbered units were verified, which the fallback already produces.
- Existing partisan entries the researcher could not confirm were kept with cleaned formatting; only garbles, duplicates, cross-tradition and disproven entries were dropped.
- Respellings: 'Piemonte Reale Cavalleria', 'Cavalleggeri di Monferrato/Alessandria', 'Ariete II', 'Centauro II', 'Sergio Toja', 'Pedro Ferreira', 'Massenzio Masia', 'Andrea Paglieri' (20a), 'Giorgio D'Avito', 'Astolfo Lunardi', 'Sibille' as 1a and 'Pescatori' as 2a Divisione Libica, "Divisione Somala", "Fanteria di Marina", "Aviotrasportabile", "Autotrasportabile" for 103-105.
- File: INEX header, nine section banners, group notes; vanilla template comments, dead self-links and TODO notes removed; 4-space indents normalized to tabs.
