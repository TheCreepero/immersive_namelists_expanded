# Division template historical names system for Iran / Persia (PER).
# Immersive Namelists Expanded (INEX)
#
# Romanization: plain period transliteration of Persian (no macrons), with the
# izafe linker written as "-e" after consonants and "-ye" after vowels,
# e.g. "Lashkar-e 1-e Piyadeh-ye Tehran" (1st Infantry Division "Tehran").
# Place names follow Pahlavi-era usage (Rezaiyeh, Bandar Shahpur, Bandar Pahlavi).
#
# No vanilla PER namelist group is referenced by focus trees or scripted effects,
# so every vanilla stub below is safely overridden with a full list.
