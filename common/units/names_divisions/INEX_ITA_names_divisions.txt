# Division template historical names system for Italy (ITA).
# Immersive Namelists Expanded (INEX)
#
# Italian nominative forms. Feminine ordinals are written "1a" (Divisione, Brigata, Banda),
# masculine ones "1°" (Reggimento, Gruppo); nicknames go in single quotes.
# Motorized, mechanized, armored and paratrooper groups link numbering to ITA_INF_01 and
# key each entry by its real division number, so a division shares its number with its
# infantry parent (e.g. 9a 'Pasubio').
#
# Overrides vanilla ITA_INF_01, ITA_INF_02, ITA_COL_01-03, ITA_CAV_01-06, ITA_MOT_01,
# ITA_MEC_01, ITA_ARM_01, ITA_MAR_01, ITA_MNT_01, ITA_PAR_01 and ITA_GAR_01. Focus trees and
# scripted effects reference ITA_INF_01, ITA_INF_02, ITA_COL_01 and ITA_CAV_02/03/05 (kept
# here) and ITA_CAM_01/02 (left to vanilla).
#
# Ideology-gated groups: Blackshirt (fascism), Royal Army (neutrality/democratic),
# Communist, the partisan formations (by party) and Legione Romana (fascism, players only).
