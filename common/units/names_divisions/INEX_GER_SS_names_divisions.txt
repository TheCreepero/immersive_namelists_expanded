# Division template historical names system for Germany (GER): Waffen-SS.
# Immersive Namelists Expanded (INEX)
#
# Every group in this file is fascist-only (has_government = fascism).
# Designations follow the Waffen-SS forms of 1940-45 (SS-Division (mot.), SS-Panzergrenadier-Division,
# Waffen-Grenadier-Division der SS ...); honour names go in single quotes, volunteer numbers in brackets.
#
# Numbering: GER_SS_02 to GER_SS_07 link to GER_SS_01, so every SS division keeps one number across
# types (1. SS-Division (mot.) 'Leibstandarte SS Adolf Hitler' becomes 1. SS-Panzer-Division). Historical
# divisions sit on their real numbers; numbers 23, 29, 30 and 33 were reassigned historically, so two
# different divisions share them. From 42 upward every list carries the same honour name for the same
# number, so whichever type claims a number gets its name.
#
# Overrides vanilla GER_SS_01 (referenced by vanilla focuses and SS_scripted_effects).
