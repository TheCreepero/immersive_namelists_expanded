# Division template historical names system for Sweden (SWE).
# Immersive Namelists Expanded (INEX)
#
# Language & Orthography: Standard Swedish (svenska) with correct diacritics
# (å, ä, ö). Divisions use Roman numerals (arméfördelningarna I-IV and XI-XVI, 1942-66);
# brigades use the Brigad 49/58/66 schemes.
#
# Vanilla groups overridden here: SWE_INF_01, MOT_01, MEC_01, ARM_01 (plain variants, with
# Named counterparts), SWE_CAV_01, MAR_01, MNT_01, PAR_01 and SWE_BS_01 (fascism only).
# Ideology suites: Fascist (BS_01, FAS_01), Communist (RG_01), Democratic/Neutral (HV_01, LS_01,
# ROYAL_01), Carolean (CAR_01). Formations Sweden never fielded are extrapolations.
